# 01. 배경과 현황

신규 개발이 아니다. YK-OS에 「상담 태블릿」 메뉴가 있고, 2026-07~08 릴리즈 로그에 지속적으로 패치가 올라온다.
- 07-24 상담태블릿 게시판 추가 / 07-30 약정 사항 문구 변경
- 08-06 고객 태블릿 full-screen, 외부화면 공유 허용 시점을 처음 미러링 시로 변경, 모두싸인 계약서 양식 연동 수정, 종료 후 PIP 영역 유지
- 08-11 선임 계약 페이지 템플릿 선택탭 추가, 보수조건에 출장비 항목 추가
- 08-14 모두싸인 템플릿 변경에 따른 미리보기 수정
- 08-18 성공보수 n개 입력 지원
- 08-19 사건 소분류 '기타' 시 법정사건명 처리
- 08-21 고객선택 시 바인더선택화면 스킵, 선임 단계에 희망배당부서·의견란 추가, 기존 YKOS backend API 호출로 전환
- 08-22 계약서 생성 시 인적정보 맵핑 수정
- 08-24 뒤로가기·모두싸인 나가기 오류 수정, 방문 태블릿 목록에서 단계변경 요청 중인 건 제외

핵심: **전자계약은 모두싸인(Modusign) 연동으로 이미 붙어 있고, 화면 미러링·PIP도 이미 있다.**
현재 우리가 하는 일은 그 위에 얹는 개선이다.

## 실물 바인더의 문제
- 변호사 입·퇴사가 잦아 전 지사 스탭이 매번 프린트하고 속지를 교체한다
- 업데이트마다 시간·비용이 든다
- 비치는 되어 있으나 실제 활용도가 측정되지 않는다

## 구성원바인더 PDF
`260623_[법무법인YK] 구성원바인더_법원.pdf` — **512MB**, 16페이지(표지1 + 프로필13 + 연락처1). Illustrator 제작.
수록 인물은 전부 사내변호사이며 YK-OS 맨파워 통합검색에서도 조회된다. **즉 바인더는 원본이 아니라 기존 데이터의 출력물이다.**
'법원' 편이므로 검찰·경찰 등 다른 출신 편이 별도로 존재할 가능성이 높다.

## 연결된 다른 과제
- **상담 녹취** (Confluence 283049986): 사전고지 없이 선녹취 → 상담 종료 시점 만족도 설문에 녹취 동의 문항 삽입 → 미동의 시 폐기.
  설문은 상담실장·변호사가 가격전략 논의로 자리를 비운 사이 고객이 태블릿으로 진행. **온라인 바인더와 노출 시간대가 겹친다.**
- **회원정보 표준화**: 비즈니스 절차 콜 → 방문예약 → 상담 → 수행 → 종결 → 추심. 상담 태블릿은 '상담' 구간.
