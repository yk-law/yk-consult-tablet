# 00. 여기부터 읽으세요

Cursor로 이 프로젝트를 처음 여는 사람을 위한 안내입니다.

## 1. 일단 돌려 보기

```bash
node tools/dev.mjs
```

http://localhost:5173 을 엽니다. Node가 없으면 `app/index.html` 을 그냥 열어도 똑같이 동작합니다.

**처음 보이는 화면은 "미연결" 상태입니다.** 이게 정상입니다.
상단 세그먼트에서 `상담실장 YK-OS` 로 바꾸고, 방문 예정 목록에서 아무 고객의 **「화면 공유」**를 눌러 보세요.
그때부터 고객 태블릿에 인사 화면이 뜹니다. `나란히` 로 두면 양쪽을 같이 볼 수 있습니다.

바로 특정 화면을 보고 싶으면:
```
localhost:5173/?c=이도현&s=brief&v=both     예약 정보 확인 (교차검증 있음)
localhost:5173/?c=김서준&s=brief&v=os       교차검증이 불가능한 케이스
localhost:5173/?c=정하윤&d=박찬&v=os         변호사 상세
localhost:5173/?v=os                        YK-OS 미연결 상태
```

## 2. 5분 안에 맥락 잡기

## 3. 이 프로젝트가 하려는 것

법무법인 YK에 **직접 찾아온 고객**을 상대로, 상담 중에 변호사·업무사례·후기를 보여주는 태블릿입니다.
지금은 실물 바인더(프린트한 변호사 프로필 파일)로 하고 있습니다.

**목적은 하나입니다 — 내방 대비 선임율.**
화면이 예뻐지는 것도, 기능이 많아지는 것도 그 자체로는 성과가 아닙니다.
새 기능을 제안할 때는 "이게 선임 결정에 어떻게 작용하는가"를 먼저 답할 수 있어야 합니다.

## 4. 기기가 두 대라는 것

이 프로젝트에서 제일 자주 오해받는 부분입니다.

| | 상담 태블릿 | YK-OS |
|---|---|---|
| 쓰는 사람 | 내방 고객 | 상담실장 |
| 기기 | 상담실 태블릿 | 데스크탑 |
| 로그인 | 없음 | 있음 |
| 하는 일 | 보기 · 담기 · 전자서명 | 실무 전부 |

**한 화면의 모드 전환이 아닙니다.** 프로토타입에서 상단 세그먼트로 오가는 건 두 기기를 한 화면에서 같이 보려는 시연 장치일 뿐입니다.

YK-OS 안에서는 다시 좌/우로 나뉩니다. **좌 = 상담실장이 보는 화면, 우 = 고객 태블릿 미러링(보기 전용).**

## 5. 손대기 전에 알아두면 좋은 것

- **`app/` 만 고칩니다.** `dist/`·`mockups/yk-binder-app.html` 은 `node tools/build.mjs` 결과물이라 덮어써집니다.
- 시연 내용(예약자·사건·콜 메모)을 바꾸는 건 대부분 **`app/data/bookings.js`** 한 파일입니다.
- 화면을 고쳤으면 `node tools/check.mjs` 로 전 화면을 훑습니다. (`npm i -D playwright && npx playwright install chromium` 최초 1회)
- **근거 없는 숫자를 화면에 띄우지 않습니다.** 실제로 그 실수를 한 적이 있어 `docs/04` 에 남겨두었습니다 — 「업무사례 1,839건」은 출처를 못 찾아 제거했고, 변호사 명단에는 고문·전문위원 17명이 섞여 있었습니다.

## 6. 아직 진짜가 아닌 것

프로토타입이라 실제와 다른 부분을 미리 알아두세요.

- **미러링**은 같은 페이지 안에서 DOM을 복제한 것입니다. 실제로는 기기 간 세션 채널이 필요합니다.
- **예약 4건**은 전부 가명 더미입니다. 실데이터는 YK-OS 콜 탭에서 옵니다.
- **콜 메모 요약**은 손으로 쓴 것입니다. 실제로는 원문 1,300자를 6문장으로 줄이는 생성 단계가 필요합니다.
- **브랜드 영상**은 홈페이지 URL을 직접 참조합니다. 태블릿에 동봉하거나 사내 호스팅해야 합니다.
- **약정금 백분위**는 실제 계약 101건에서 뽑은 값이지만, **사건유형별 표본 수(n)는 재검증이 필요합니다.**
