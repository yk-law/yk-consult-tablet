## YK-OS (ykos.yklawfirm.co.kr) — React SPA + REST API
**DOM 스크래핑 금지.** 클래스명이 빌드 해시라 배포마다 깨진다. `/v1/` API를 쓴다.

| `GET /v1/authority` | 권한 |
| `GET /v1/customer/company/list` | 기업 고객 |
| `GET /v1/employee/me`, `/v1/nworks/me/permissions` | 로그인 사용자·권한 |

- `/#/app/visit` 미러링 화면이 개편되어 있음: 좌측 방문 예정 목록 + 우측 「고객화면(미연결)」 미리보기. 연결 순서는 ① 태블릿 앱에서 이름 입력 후 입장 ② 목록에서 태블릿 선택 ③ 방문 예정 목록에서 고객 선택.
- 방문 예정 목록에는 실제 의뢰인 실명·전화번호가 노출되므로 명단은 추출·저장하지 않는다.

**중요 — 이전 데이터의 오류를 정정함.**
- 기존 `lawyers.txt`(329건)는 `/member/all` 숨은 자동완성 DOM에서 뽑은 것이라 **고문·전문위원·자문위원 17명이 변호사로 섞여 있었다**
  (강성용·이용만·강정선·김수환·박남희·박대훈·이광희·이상경·이상관·이상국·이승규·이한영·임만영·임영빈·전창일·최계원·장규호).
  실제로 목업 추천 순위표에 전문위원 임만영이 변호사로 올라왔었다.
- 정정 방법: **`/member/lawyer` 20페이지를 전수 파싱**해 권위 있는 변호사 명단을 만들고, 거기에 기존 분야 태그를 매칭했다.
  파싱 정규식은 `/([가-힣]+)변호사\n/` 로 잡은 뒤 접미사 `대표|파트너|고문` 을 제거해야 한다
  (`[가-힣]{2,4}` 로 잡으면 "한만수대표변호사"가 "만수대표"로 잘린다).
- 결과: `data/lawyers.txt` = **316개 고유 이름**. 318건과의 차이는 **동명이인 2쌍(이솔·조아라)** 이며, 이름 기반 모델이라 목업에서는 1건으로 합쳐진다.
  → **YK-OS 사번(employee id) 기반으로 바꿔야 근본 해결**된다. `docs/06` 1번 항목과 같은 문제.
- 태그 없는 변호사 4명: 강경훈(수동 `AJ`), 정창호(수동 `F`), 이재성, 이희래. 뒤 둘은 홈페이지에도 전문분야 태그가 없어 검색으로만 잡힌다.
- **이재성은 변호사와 고문에 각각 존재하는 동명이인**이다. 병합하지 말 것.
- 직위(`POS`)도 `/member/lawyer` 게재 순서 기준으로 정정: **대표 19 · 고문 2(양동학·변광호) · 파트너 37**.

## app/data/scenarios.js — 확장 질문 시나리오
사건 종류별 파생건과 확인 질문. 소분류(cat2) 키가 우선, 없으면 대분류(cat1) 폴백.

현재 등록: **소분류** 이혼 · 사실혼관계해소 · 상속 · 유류분 · 손해배상 · 경제범죄고소 · 협박 · 법률자문 /
**대분류** 가사 · 민사 · 고소·고발 · 강력범죄 · 성범죄 · 군형사

- 형식: `{ k:"파생 사건명", q:"확인 질문" }`
- 질문은 **고객에게 그대로 읽어줄 수 있는 문장**으로 쓴다. 법률용어를 나열하지 않는다.
- 파생건을 늘리기 전에 **YK-OS `/v1/incident_category` 의 실제 분류 체계와 맞출 것.** 지금은 홈페이지 기준 명칭이라 YK-OS 코드와 1:1이 아니다.
- 검증 필요: 각 파생건이 실제로 YK가 수임하는 범위인지, 선임 계약을 별건으로 나누는지 한 건에 포함하는지.

## 시연 API 카탈로그 (2026-09-16)
목업 JSON은 `server/data/*.json` 이다. FastAPI가 읽어 추천 점수·계약 초안을 계산한다. vanilla JS 원본은 `vanilla/data/` 에 남아 있고, `tools/export-json.mjs` 로 JSON을 다시 뽑을 수 있다. 화면 수치의 출처·검증 기준은 이 문서의 위 표와 같다.

## 홈페이지 프로필 명언·사진 (2026-09-18)
- 카드 카피는 `/member/lawyer/{id}` 의 따옴표 명언. 김동진 예: `https://www.yklawfirm.co.kr/member/lawyer/6254` 「어려움에 처한 의뢰인을 정성으로 돕겠습니다.」
- 한상진은 바인더 13장에 없어 `photo: false` 였다. 홈페이지 `https://www.yklawfirm.co.kr/member/lawyer/6071`, 이미지 `/upload_file/lawyer/한상진.png`. 경력·학력·명언을 `lawyers.json` 에 넣었다. 이메일·전화번호는 넣지 않는다.
- 같은 경로로 사진이 없던 배성범·양호산·최영운·천기홍 PNG를 jpeg로 줄여 `portraits.json` 에 추가 (13장 → 18장).
- 고문·전문위원·자문위원 상세 사진은 이번 수집에 포함하지 않았다. 시연은 이름 이니셜 + 별도 프레임.
  → **변경됨 (2026-09-22)** 시연 카드 3인만 홈페이지에서 채움. `docs/04` 아래 「고문·위원 시연 3인」.

## 고문·위원 시연 3인 (2026-09-22)
출처: `https://www.yklawfirm.co.kr/member/all?keyword=` 검색 후 상세.

| 이름 | 역할 | 상세 | 사진 |
|---|---|---|---|
| 강성용 | 고문 | `/member/advisory/6148` | `/upload_file/lawyer/2025/09/09/20250909_090413920.png` |
| 강신선 | 전문위원 | `/member/expert/6018` | `/upload_file/lawyer/강신선.png` |
| 김한기 | 자문위원 | `/member/consultant/6023` | `/upload_file/lawyer/김한기.png` |

- 넣은 값: 직위, 대표 경력 뱃지(`기업자문` / `경찰 경력`), 홈페이지 경력·학력·저서·수상 문구. jpeg로 줄여 `portraits.json` 18장 → 21장.
- **넣지 않음**: 이메일, 전화번호, 생년월일, 「전관」, 근거 없는 수치. 홈페이지 경력 오탈자(`걍력팀장`)는 `강력팀장`으로 바로잡았다.

## 홈페이지 대표 경력 (2026-09-18)
`/member/lawyer/{id}` 의 **대표 경력** 뱃지(`styles_badgeText`). 업무분야 앞에 온다. 예: 권순일 「대법관 역임」「판사 역임」, 한상진 「부장검사 역임」「검사 역임」. `lawyers.json` `d.titles`.  vis 화면에서 사진 바로 아래 골드 세리프로 가장 크게 보여 준다.
