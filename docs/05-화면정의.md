## 상담 태블릿 (고객)

화면은 **연결 상태에 따라 두 갈래**다. 상담실장이 YK-OS에서 「화면 공유」를 누르기 전/후.

0. **대기 화면 · 미연결** (기본) — 브랜드 영상 전면 재생(`/video/main_video.webm`, 무음·반복·autoplay·playsinline) + **공식 로고**(화이트 반전) + 카운터(**변호사 318 / 고문·위원 98 / 전국 사무소 31**) + "상담실장이 안내해 드릴 때까지 잠시만 기다려 주세요". **인사도, 시작 버튼도 없다.**
1. **대기 화면 · 연결됨** — 같은 영상 위에 **「안녕하세요 ○○○ 님」**(가명) + 방문 일시·상담실·사건 종류 + 「상담을 시작할게요」.
2. **예약 정보 확인** — 「예약해주신 정보를 기반으로 미리 추천 리스트를 준비했습니다」
   - **예약 카드** — 유형(개인/기업) · 역할(사건 당사자/사건 위임인/추천인/기타, 사건 당사자와의 관계 병기) · 사건 종류(대 › 소) · 방문 일시/상담실. 전부 YK-OS 콜 탭 필드를 그대로 따른다.
   - **콜 메모 교차검증** — `사건개요(영업전략팀)`를 문장 6개 안팎으로 요약하고, 각 문장에 「맞아요 / 달라요」. 「달라요」 문장은 붉게 표시되고 YK-OS에 즉시 정정 요청으로 뜬다.
   - CTA 「네, 맞습니다 · 추천 변호사 보기」 / 보조 「나중에 확인할게요」. 이 화면에서도 하단 탭을 숨긴다.
3. **예약 확인 이후 — 두 갈래로 갈린다**
   - 「네, 맞습니다 · 추천 변호사 보기」 → **추천 목록**. 추천 **상위 3인**(01/02/03 + 이유 칩)이 주인공. 검색창(이름·분야·출신·직위·경력). 전체 목록·분야 그리드는 없앴다.
   - 「나중에 확인할게요」 → **둘러보기**. 사건 정보가 확정되지 않았으니 추천을 앞세우지 않는다.
     - 상단에 골드 배너 「예약 정보 확인 · 확인해 주시면 사건에 더 맞는 변호사를 보여드립니다 → 확인하기」 (누르면 예약 확인 화면으로 되돌아간다)
     - 검색 → 바로가기 3개(업무사례 / 의뢰인 후기 / 고문·전문위원) → 맨 아래 **참고 추천**("아직 확인 전이라 정확도가 낮을 수 있습니다")
   - 하단 `변호사` 탭은 고객이 어느 경로에 있는지에 따라 추천 목록 / 둘러보기로 각각 돌아간다.
4. **프로필 상세** — 사진·직위·출신·분야 / 추천 이유 / 주요 경력(**사건 유형 기준 연관순 정렬**, `관할 법원`·`같은 분야` 태그) / 주요 업무사례(또는 저서·논문) / **비용 안내**(약정금 p25~p75 + 중앙값 + 성공보수 방식) / 관련 업무사례 / 이 변호사 후기 / CTA 「이 변호사로 상담받고 싶어요」 → 상담실장에게 전달
5. **전문가** — 고문 28 · 전문위원 61 · 자문위원 9 = **98명**. 전체/고문/전문위원/자문위원 필터. 이름 + 경력 라벨만.
6. **관심** — 별표로 담아둔 변호사. YK-OS에 실시간 전달.
7. **하단 탭** — 변호사 · 전문가 · 관심 · 업무사례 · 후기 (대기 화면·예약 확인 화면에서는 숨김)

**처분권자 접점은 고객 화면에 노출하지 않는다** — YK-OS 전용. 고객 화면에는 "서울중앙지방법원 근무 이력" 같은 **사실 서술 칩**만 남는다.

## 상담 태블릿 (고객 View) — 2026-09-17 변경
YK-OS 미러링·화면 공유·맞아요/달라요·추천 선택 UI는 쓰지 않는다. 시연 상단에서 장면만 넘긴다.

**내방 흐름 (자동)**
1. **예약 확인** — 「예약자가 맞으신가요?」 가명·방문 일시·상담실만. 「방문 확인」 라벨은 없다. 사건 분류는 넣지 않는다. 예약 확인과 MYK QR을 화면 가운데에 한 묶음으로 둔다. QR 소개 문구는 보조 크기다.
2. **준비** — 「상담을 준비 중입니다」
3. **브랜드 필름** — 전면 재생, 끝나면 사건요약. **건너뛰기**는 처음부터 도달 가능. 가장자리·safe-area의 얇은 텍스트, 지연 페이드, 낮은 대비. 호버·탭 시에만 또렷.
4. **사건요약** — 예약 때 말씀하신 내용을 고객에게 다시 안내한다. 제목 「말씀하신 내용을 이렇게 정리했습니다」. 네 단락(**관련하신 분들 · 지금까지의 경과 · 고객님의 입장 · 오늘 상담에서 확인하고 싶은 점**). 어체는 「고객님께서는 ~라고 말씀하셨습니다 / 이렇게 정리했습니다」. 「의뢰인」「진술」「콜 단계」·YK-OS 시스템명은 쓰지 않는다. 내용이 비어 있으면 오늘 상담에서 편하게 이야기해 달라는 안내. 「오늘 상담변호사 확인하기」.
5. **오늘의 상담변호사 인터뷰** (있을 때만) — YouTube 인터뷰가 매핑된 상담변호사이면 프로필 **앞**에 전면 재생. 브랜드 필름과 같이 건너뛰기(2초 후)·끝나면 프로필로. 없으면 이 뎁스를 생략하고 바로 6.
6. **오늘의 변호사** — 전문인력 확대 화면과 **같은 프로필**. 상단은 **좌: 사진·기본정보(대표 경력·이름·직위·출신·한 줄 소개·학력) / 우: 경력**. 아래 전체 폭에 업무분야(특기 표식), 수상실적, 논문·저서(있을 때만), 업무사례, 영상. 사진은 **상반신** 크기(대략 148×186) + 직위 프레임. 사진 위 직위 태그 없음. 길면 스크롤한다.
7. **전문인력** — 이번 사건 분야에 맞는 변호사. 고문·전문위원 예시는 강성용·강신선을 함께 둔다 (2026-09-22). 자문위원은 목록에 없다. 미니 카드의 사건분야는 이번 사건과 유관한 항목만, 최대 3줄. 태그는 빗긴 특기 표식. 이번 사건명은 골드 플레이트, 같은 대분류는 골드 테두리. **미니 카드 하단은 수상실적 첫 줄**(없으면 공란). 한 줄 pitch는 쓰지 않는다. 대표 경력은 **한 줄**(길면 글자만 축소). 등급 별은 **카드 바깥 상단 테두리(사진 칸 위)**. 본문은 세로 가운데. **미니 카드를 열면 오늘의 변호사와 같은 프로필**로 업무분야 전체·경력·수상·논문·저서·업무사례를 본다. 헤드 아래 소개 「고객님의 사건을 성심껏 맡아드리기 위한 전담인력을 소개합니다」. 같은 크기 가로 카드. 상체 크롭. 대표 경력은 같은 직군이면 최고 직위만. 직위 글자는 크되 굵지 않다. 프레임은 희귀 카드. 대표 > 파트너 > 변호사, 고문 > 전문위원. 세부 프로필은 경력·수상실적·논문·저서·업무사례(변호사, 홈페이지 사례 링크)를 구분. 고객 카피에 「전관」 없음. 승소 뱃지·승소율 없음.
8. **설문** — 서명 전은 두 단계. 첫 화면 제목 「오늘 상담은 어떠셨나요?」 + 「더 나은 법률서비스 제공을 위하여…」 → 「선임했어요 / 조금 더 생각해볼게요」. 버튼이 주인공이고 MYK QR은 작게 그 아래(문구는 QR 우측). 선임·보류 문항에는 그 안내·QR을 두지 않는다. 선임 후에는 선임 원인(예약·방문 절차 포함)을 기대 부분보다 앞에 둔다. 보류 이유는 복수 선택(「시간을 두고 결정하려한다」 포함). 선택 버튼은 같은 모양. 서명 후는 계약 조건·이후 연락. 음성 녹취·승소 문항 없음.

전문인력 카드의 사진 프레임(직위별 골드 우열, 고문·위원은 실버·네이비)은 예외적으로 허용한다 (2026-09-18). 다른 장면은 선과 여백 원칙을 유지한다.
시연 프레임은 고정 16:10이 아니라 **가로를 기본으로 한 반응형**(스테이지를 채우고, 컨테이너 너비 1080·높이 680 이하에서 2단을 1단으로 접음).

이전 정의(대기 미연결 / 예약 교차검증 / 추천 3인 / 둘러보기 / 관심 탭 / 영상 위 오버레이 대기)는 위 결정으로 대체한다.

## YK-OS › 상담 태블릿 (상담실장)
좌측 메뉴 레일에서 「상담 태블릿」 진입. **상단 탭 없이 한 스크린 좌/우 분할.**
**좌 = 상담실장이 보는 화면, 우 = 고객 태블릿 연결 화면.** (2026-09-04 실화면 확인)

상단 바: 홈·문서·폴더 아이콘 / 「미러링 ●」(연결 시 초록) / `2026.09.04 13:20` / 계정.

**좌 — 상담실장 실무 화면**
- 「방문 예정 목록」 + 기간 `오늘 / 내일 / 이번주 / 다음주`(월~일, 기본 오늘) + 세그먼트 `전체 / 형사 / 민·가사`
- **검색: 고객명, 사건 유형, 연락처로 검색**
- **「선임 계약」** — YK-OS `/#/app/visit/sign` 작성 화면. 좌: 템플릿(형사/민·가사) · 사건 · **약정 조건** · **보수 조건** · **부서 배당**. 우: 소송위임계약서 원본 서식 미리보기. 「태블릿으로 보내기」는 희망 배당 부서 1 + 배당 의견이 있어야 한다.
- 연결되면 그 아래로 상담실장 전용 패널이 펼쳐진다:
  **연결됨 배너 + 「공유 해제」** / 예약 정보(콜 탭 등록값 6종) / 고객 교차검증(문장별 맞음·정정·미확인) / 고객이 담은 변호사 / 추천 순위표(분야·인접·관할·직위·합계 + 행별 화면 공유) / 선택 변호사 상세(유사 사건 수, 종결 결과 집계 없음, 제안 금액 가이드, **처분권자 접점**)

**우 — 고객 태블릿 연결 화면**
- 탭 「고객화면」 + 우측에 연결 상태(`미연결` / `본사 1상담실 · 이도현(가명) 님`)와 「공유 해제」
- *연결 전*: **다크 패널** — 공식 로고 + 「상담 태블릿을 연결하세요」 + 「미러링 시 고객 화면 미리보기가 여기에 표시됩니다」 + ①②③ 안내 + 「연결 가능한 태블릿이 없습니다」
- *연결 후*: **고객 태블릿 화면을 그대로 실시간 복제**해 태블릿 프레임 안에 축소 표시. **보기 전용**(pointer-events 없음) — 상담실장이 여기를 눌러 고객 화면을 조작하지 않는다. 하단에 현재 화면명 + 「실시간 미러링 · 보기 전용」.
- 고객 화면을 바꾸려면 좌측 추천 순위표의 행별 「화면 공유」를 쓴다.

**공유 해제**
- 세 곳에서 가능: 카드의 「공유 중 · 해제」 / 좌측 연결됨 배너의 「공유 해제」 / 우측 고객화면 탭의 「공유 해제」
- 해제하면 태블릿은 **대기 화면(브랜드 영상)으로 되돌아가고**, 담아둔 관심 변호사와 검색어도 초기화된다. 우측은 다시 다크 미연결 패널.

### 상담 내용 작성 (모달)
목록 카드의 「상담 내용 작성」을 누르면 뜬다. 현행 YK-OS 모달 그대로:
제목 `[고객명(역할) - 사건종류] 상담 정보` · `AI 리포트` · `eng_id` · 탭 **1 콜 / 2 상담 / 3 선임 / 4 부서 배당 / 5 사건 수행 / 6 종료** ·
하단 `미방문 처리 / 승인 요청 / 정보 저장 / 상담 완료`.

**온라인 바인더가 바꾸는 것은 콜 탭뿐이다.** 선임·배당·수행·종결 흐름은 손대지 않는다.

콜 탭 블록: 기본 정보 / 고객 정보 / 상담 정보 / 상담 기록 / 금액.

**바인더에서 확인된 내용이 이 화면으로 자동으로 넘어온다** — 상담실장이 옮겨 적지 않는 것이 핵심이다.

| 넘어오는 값 | 들어가는 칸 | 표시 |
|---|---|---|
| 콜 메모 원문 | 사건개요 (영업전략팀) | `고객 확인 반영됨` |
| 고객이 「달라요」 한 문장 | 사건개요 아래 정정 박스 | `고객이 다르다고 표시한 문장 N건` (버건디) |
| 고객이 담아 둔 변호사 | **부서 배당 의견** | `고객 관심 N명` |
| 약정금 분포 | **제안 금액** | `약정금 실적` + 사건유형·표본수·중앙값 |

- 교차검증이 없었던 예약은 사건개요 칸에 「콜 단계에서 사건 내용을 받지 못했습니다 + 사유 + 상담에서 처음부터 청취해 이 칸을 채우세요」가 들어간다.
- 제안 금액은 **가이드**이며 확정 금액이 아니라는 문구를 칸 아래에 붙인다.
- **위임 사무는 자동으로 채우지 않는다.** 상담실장이 직접 적는 칸이다. 확장 질문 시나리오는 참고용으로 좌측에만 띄우고 폼에는 넣지 않는다.
- 소득·총자산은 현행 그대로 두되 고객 태블릿에는 절대 노출하지 않는다.

## 미러링
YK-OS 방문 예정 목록에 **이미 「미러링」 버튼이 있다.** 온라인 바인더는 그 버튼이 여는 세션 위에 얹는다.
양방향: 고객 화면 → 데스크탑 / 상담실장이 고른 변호사 → 태블릿
